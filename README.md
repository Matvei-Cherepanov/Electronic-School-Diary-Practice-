# Electronic-School-Diary-Practice

## Электронный дневник

Электронный дневник — это приложение для удобного отслеживания успеваемости и посещаемости учеников и родителей, а также эффективный инструмент, ускоряющий работу педагогов и администраторов школы.

## Инструкция по запуску

Сборка и запуск:

- Скачайте или склонируйте репозиторий.

- Откройте проект в IntelliJ IDEA.

- Убедитесь, что установлена Java 11 или 17.

- ля сборки выполните в терминале mvn clean install (Maven) или ./gradlew build (Gradle).

- Запустите главный класс с методом main через IDE либо выполните java -jar target/diary.jar в командной строке.

- Сервер поднимется по адресу http://localhost:8080 — откройте браузер и перейдите туда.
